# Basic Chatbot 🤖

A simple rule-based chatbot built in Python — created for the **CodeAlpha Python Programming Internship (Task 4: Basic Chatbot)**.

## About

This chatbot responds to a set of predefined user inputs like greetings, questions about itself, and requests for help. It runs in the console and keeps chatting with the user until they type "bye", "exit", or "quit".

## Features

- Responds to common greetings ("hello", "hi", "hey")
- Answers simple questions like "how are you" and "your name"
- Provides a "help" command listing what it can do
- Exits gracefully when the user says "bye", "exit", or "quit"
- Falls back to a polite default reply for anything it doesn't understand

## Concepts Used

- `if-elif` conditional statements
- Functions
- Loops (`while`)
- Input/output handling

## How to Run

1. Make sure Python 3 is installed on your system.
2. Run the script:

```
python CodeAlpha_Chatbot.py
```

3. Start chatting! Type messages like `hello`, `how are you`, or `help`.
4. Type `bye` anytime to end the conversation.

## Example

```
Chatbot: Hi! Type 'bye' anytime to exit.
You: hello
Chatbot: Hi! How can I help you today?
You: how are you
Chatbot: I'm fine, thanks! How about you?
You: bye
Chatbot: Goodbye! Have a great day.
```
